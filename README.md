# 物品管家

管理三类东西的手机 App，iOS 和安卓共用一套代码（Expo / React Native）。

| 类别 | 能做什么 |
| --- | --- |
| 食品 | 扫条码录入，填过期日期（直接选，或按「生产日期 + 保质期」自动算），记库存和每次入库的进价（选填）；快到期、已过期、库存不足时提醒 |
| 日用品 | 和食品一样扫码录入、记库存和进价、库存不足提醒；过期日期可以不填 |
| 设备 | 电脑及配件：扫包装盒上的序列号条码录入（登记过的直接打开）；常用设备快速选择（登记过的组合 + 内置 Mac 机型）；类别、名称、型号、电脑的芯片 / 内存 / 硬盘（分开记，Mac 可点选）、序列号、数量、购买日期、发票号、保修、随设备的配件；同款可「保存并扫下一台」批量登记；登记谁领走（使用人、数量、领取日期）和退还日期，支持部分退还，留全部领用记录 |

另外可以定期**盘点**（按实际数量调整库存），看**报表**（进货、消耗、库存和设备统计）并导出成表格。

三类东西都可以分**办公点**管理，按办公点导出导入，在手机之间传数据（不需要服务器）。

## 功能说明

- **扫码**：认识的条码直接打开该物品，选「入库」或「出库 / 用掉」；没见过的条码进新建页，并去 Open Food Facts 开放商品库查名称（只发送条码；国产商品收录不全，查不到就手填，手填一次后本机就记住了）。
- **出入库**：物品详情页点「入库」「出库 / 用掉」，扫已录过的条码会直接打开它。同一商品买了好几次、过期日期不同，会分批记录；出库时先扣最早到期的那批，可以选原因（用掉、过期丢弃、坏了、送人、其他）。
- **进价**：入库时可以填单价和总价，都是选填（建议填）。填了单价按数量自动算总价，填了总价按数量自动算单价，改数量时另一个跟着重新算。单价按入库时选的单位算（按箱入库就是每箱的价，单位从瓶换成箱时单价跟着换算，如每瓶 2 → 每箱 48）。每次入库的价格单独记在那条入库记录上，以后价格变了不影响以前的记录；同一物品再入库时单价默认填上一次的价（按这次的单位换算），可以直接改；新建物品时的「这次入库」也能填。详情页「信息」里显示上次进价。价格只记数字，不带货币符号。
- **整箱进、按个出**：每个物品按「最小单位」（瓶、个、包…）记库存，可以另设包装规格，如「1 箱 = 24 瓶」「1 提 = 6 瓶」。入库、出库时都能选按箱、按提还是按瓶填，自动换算；库存显示成「50 瓶（2 箱 2 瓶）」。整箱外包装上的条码可以录到对应的包装规格里，扫箱子会直接认出这个物品，并默认按箱入库。库存下限按最小单位填。
- **出入库记录**：每次入库、出库、手动改批次都记一条流水（时间、数量变化、原因；按箱进出的会注明「按 2 箱」；入库填了价格的会显示单价和总价），在物品详情页查看。
- **提醒**（设置页可改）：
  - 到期前几天开始提醒（默认 7 天；单个物品可另设）
  - 多久提醒一次：每天 / 每 2 天 / 每 3 天 / 每周（到期当天一定提醒）
  - 每天几点提醒（默认 09:00）
  - 库存下限：库存 ≤ 下限时提醒补货（每个物品单独设，留空不提醒）
  - 用的是手机本地通知，不需要服务器；每次打开 App 或改库存都会按最新数据重排未来 60 天的提醒。
- **提醒页**：汇总已过期、快到期、库存不足和借出中的设备，点进去直接处理。上方有「盘点」「报表」两个入口。
- **盘点**：
  - 开始时选办公点和范围（食品、日用品、设备，默认食品和日用品）；同一办公点同时只能有一次进行中的盘点，已有时可以「接着盘那一次」。
  - 逐项清点：点一行填实盘数量（可按箱或按瓶），「和账面一样」一键保存，也能「改回未盘」；可扫物品条码、包装条码或设备序列号直接定位，也能按名称、条码、序列号搜；筛选全部 / 未盘 / 有差异。数量随填随存，离开后回来接着盘。
  - 「完成盘点」后按「实盘 − 清点时的账面」调整库存，清点之后又入库出库的不受影响：盘亏先扣最早到期的批次，盘多了并到最早到期的那一批（没有批次就新建一批）；每项记一条「调整」出入库记录，备注写「盘点：账面 10，实盘 8」。没盘的不调整。完成后不能撤销。
  - 设备盘的是在库数量（总数减借出），只记差异，不自动改数量，丢失或报废要到设备里手动处理。
  - 可以「放弃这次盘点」，库存不变，盘点单留在历史里；已完成的盘点能查看结果和差异，导出 CSV。
- **报表**：
  - 按办公点（可看全部）和时间段（本月、上月、近 3 个月、今年）看。进货、消耗、物品明细按时间段统计，库存概况和设备是当前情况。
  - 库存概况：食品、日用品各几种，库存不足 / 快到期 / 已过期，点开看名单。
  - 进货：金额合计、入库次数、按分类的金额、金额前 10；没填价格的入库不算进金额，会注明次数。
  - 消耗：按出库原因的次数、用得最多的前 10；「过期丢弃」「坏了」单独列出，按出库前最近一次进价估算损失，没有进价的不算进合计。
  - 物品明细：每个物品这段时间的入库、出库、现有数量和进货金额（盘点调整不算在入库、出库里）。
  - 设备：总数、借出、在库及按类别统计，保修 30 天内到期和已过保，领用排行。
  - 导出三个 CSV 表格（出入库明细、当前库存、设备清单），Excel / WPS / Numbers 能直接打开，通过系统分享发出去。
- **导入导出**（设置页）：
  - 导出：生成一个备份文件 `item-keeper-backup-日期-时间.json`，包含全部物品、包装规格、批次、出入库记录（含入库的单价、总价）、设备（含发票号、芯片、内存、硬盘）、领用记录和提醒设置，通过系统分享存到「文件」、网盘或发给自己。
  - 导入：选一个备份文件，先整份校验（哪条数据哪个字段不对会直接说出来，不会导入一半），确认后替换手机上现有的全部数据。
  - 按分类：导出时可以只勾食品、日用品、设备、提醒设置里的几类；导入时也只替换勾选的分类，没勾的原样保留（会先检查导进来的条码和保留下来的物品有没有重复）。
  - 撤销：导入前会自动把现有数据留一份，导错了可以在设置页「撤销上次导入」。
  - 备份提醒：超过 N 天（默认 60，设置里可改，0 为不提醒）没完整导出（食品、日用品、设备三类都勾上），提醒页显示「该备份了」并发通知，之后每 7 天一次；上次备份时间只记在本机，不随备份文件走。
  - 版本：1.3.x 导出的备份可以导入 1.4.0 及以后的版本（只是没有价格和发票号）；1.4.0 及以后导出的备份不能导入 1.3.x 的 App，会提示先升级。
  - 盘点记录不进备份文件，只存在这台手机上；盘点产生的库存调整是出入库记录，会随备份带走。
- **办公点**（设置页管理）：每样东西属于一个办公点；有多个办公点时各页右上角切换或看全部；条码在同一办公点内唯一。
- **手机互传**：导出时选办公点和分类，用聊天软件、隔空投送、快传发给别的手机；对方导入时只替换本机对应办公点的对应分类，办公点按名称对应，本机没有就新建。约定每个办公点由一台手机负责记账，就不会冲突。
- **数量输入**：所有数量框都可以直接输入或点 − / +，只接受数字。
- **手势**：列表里点开看详情、长按编辑；向左滑时这一行不动，红色「删除」从右边滑出来盖住右侧的数量，名称和标签照常显示，点「删除」就删（底部 5 秒内可撤销）；滑开后点这一行或向右滑收回，同一时间只有一行滑开。五个标签页可以左右滑动切换。
- **定位起名**：添加或改名办公点时，可以用当前位置反查地名给出候选名字（系统查不到时用 OpenStreetMap）。
- **数据**：存在手机本地 SQLite 里，不经过服务器。盘点记录也只在本机，不进备份。

## 在手机上试用（不用装 Xcode / Android Studio）

1. 手机装 **Expo Go**（App Store / Google Play 搜 “Expo Go”）。
2. 电脑上：
   ```bash
   cd ~/code/item-keeper
   npm install
   npx expo start                  # 手机和电脑在同一 Wi-Fi
   npx expo start --tunnel ngrok   # 不在同一网络时用这个（要先 npm i -g @expo/ngrok）
   ```
3. iPhone 用相机扫终端里的二维码，安卓用 Expo Go 扫，就能打开。

扫码、本地通知、SQLite 在 Expo Go 里都能用。

## 打成安装包

**安卓（本机打，不需要账号）**：装好 JDK 和 Android SDK 后运行 `scripts/build-android.sh`（脚本开头写了要装哪些），产物在 `dist/item-keeper-<版本>.apk`。用的是调试签名，只适合自己装，不能上架。

**iOS** 要么用 Expo Go 试（见上一节），要么有苹果开发者账号后用 EAS 云端构建。

用 EAS 云端构建（安卓 / iOS 都行，本机不需要 Xcode / Android Studio，需要一个免费的 Expo 账号）：

```bash
npx eas-cli@latest login
npx eas-cli@latest build:configure          # 首次会问 iOS bundle id / 安卓包名
npx eas-cli@latest build -p android --profile preview   # 出 apk，直接发给别人装
npx eas-cli@latest build -p ios                          # 需要 Apple 开发者账号
```

## 开发

```bash
npm run typecheck   # TypeScript 检查
npm run lint        # ESLint
npm test            # 单元测试 + 用 Node 自带 SQLite 跑真实迁移和读写的数据层测试
```

目录：

```
src/app/            页面（expo-router，文件即路由）
  (tabs)/           底部五个标签：提醒、食品、日用品、设备、设置
  scan.tsx          扫码页
  stock/            食品 / 日用品的新建、详情（入库出库）、编辑
  device/           设备的新建、详情（领用退还）、编辑
  stocktake/        盘点列表、盘点单与结果
  report.tsx        报表与导出表格
src/db/             SQLite 表结构与查询
src/lib/            日期、提醒排程、包装换算、备份格式校验、盘点差异、报表汇总、CSV（纯函数，有单测）、通知、条码查询、导入导出
src/components/     通用组件
tests/              单元测试
```

## 目前的限制

- 数据只在一台手机上；多人 / 多设备共用需要加服务端同步。
- 导入是整份替换，不做两份数据的合并。
- 国产商品条码联网查名经常查不到，需要手填一次；如果要查得全，可以接中国物品编码中心等付费接口。
- App 图标和启动图还是 Expo 默认的。
